KIRTHIKA PORTFOLIO

This version keeps the original portfolio look/background for the main sections and uses the animated stacked Projects section from the reference folder.

Run:
1. Open this folder in VS Code.
2. Open Terminal.
3. Run: npm install
4. Run: npm run dev
5. Open the local Vite URL shown in the terminal.

Contact form:
- Visitor enters name, email and message.
- The form sends to kirthika2058@gmail.com through FormSubmit AJAX.
- On the first real submission, FormSubmit may send an activation/confirmation email to that mailbox. Confirm it once so future submissions are forwarded.
